### 1. 受苦仙人 🩸
- **核心驱动力**: 征服高难挑战的快感，痛苦兑换优越感
- **现代子类目**: 魂类、银河城、高速动作、Boss Rush
- **推荐游戏**: 艾尔登法环、只狼、空洞骑士·丝之歌、黑神话悟空、仁王2、匹诺曹的谎言
- **口头禅**: "死第50次了，这次一定过"

### 2. 天亮战士 🌅
- **核心驱动力**: 决策本身的快感，脑内多巴胺循环
- **现代子类目**: 大战略、即时战略、肉鸽卡牌、回合制战术、自走棋、4X策略
- **推荐游戏**: 文明7、杀戮尖塔2、小丑牌、群星、钢铁雄心4、十字军之王3
- **口头禅**: "就再玩一回合……"

### 3. 赛博驴友 🎒
- **核心驱动力**: 好奇心驱动，地图上每个"?"都是使命
- **现代子类目**: 开放世界角色扮演、生存探索、沉浸模拟、步行模拟
- **推荐游戏**: 赛博朋克2077、荒野大镖客2、塞尔达传说、原神、绯红沙漠
- **口头禅**: "那座山能爬吗？"

### 4. 天梯卷王 🏆
- **核心驱动力**: 排位分 = 自我价值，赢的渴望永不满足
- **现代子类目**: 战术射击、多人在线竞技、大逃杀、格斗游戏、英雄射击、体育竞技
- **推荐游戏**: CS2、无畏契约、英雄联盟、APEX英雄、街霸6、漫威争锋
- **口头禅**: "赢一把就睡"

### 5. 产线仙人 ⚙️
- **核心驱动力**: 看到混乱的系统本能地想优化到完美
- **现代子类目**: 工厂自动化、殖民模拟、资源管理、编程游戏
- **推荐游戏**: 异星工厂、幸福工厂、环世界、缺氧、戴森球计划
- **口头禅**: "这条传送带还能再优化"

### 6. 方块狂人 🧱
- **核心驱动力**: 创造本身就是目的，过程比结果重要
- **现代子类目**: 沙盒建造、模拟经营、城市设计、生活模拟
- **推荐游戏**: 我的世界、泰拉瑞亚、城市天际线、动物园之星、模拟人生4
- **口头禅**: "等我造完这个就睡"

### 7. 语音永动机 🎙️
- **核心驱动力**: 游戏是社交的载体，一个人在游戏里 = 孤独
- **现代子类目**: 派对游戏、合作生存、社交推理、大型多人在线、社交VR、非对称对抗
- **推荐游戏**: 绝地潜兵2、REPO、VRChat、双影奇境、太空杀、最终幻想14
- **口头禅**: "开黑吗？我带气氛组"

### 8. 648战士 💰
- **核心驱动力**: 清醒地知道自己被割韭菜，但出货那一刻值了
- **现代子类目**: 氪金抽卡、战令通行证、限定池、手游卡池
- **推荐游戏**: 原神、崩坏星穹铁道、赛马娘、命运冠位指定、绝区零
- **口头禅**: "这发十连必出"

### 9. 老六鼠鼠 🐭
- **核心驱动力**: 苟到最后就是胜利，风险规避是最高策略
- **现代子类目**: 撤离射击、生存游戏、战术射击、潜行
- **推荐游戏**: ARC Raiders、塔科夫、猎杀对决、DayZ、Rust
- **口头禅**: "走过路过不要错过……有人！蹲下"

### 10. 肝帝 💪
- **核心驱动力**: 用时间对抗金钱的悲壮英雄主义
- **现代子类目**: 大型网游、刷子动作角色扮演、零氪搬砖、暗黑类
- **推荐游戏**: 星际战甲、流放之路、失落的方舟、暗黑破坏神4、梦幻西游
- **口头禅**: "零氪全通，肝就完了"

### 11. 传奇老鹅 🦆
- **核心驱动力**: 承认精力有限、退出竞争、享受"无意义之意义"
- **现代子类目**: 治愈系、放置点击、种田、模拟、音游、拼图
- **推荐游戏**: 星露谷物语、欧卡模拟2、旅行青蛙、心之桃源、冲就完事模拟器
- **口头禅**: "今天也要做只快乐老鹅"

### 12. 仓鼠症晚期 🐹
- **核心驱动力**: "拥有"本身就是安全感，消耗品焦虑症
- **现代子类目**: 收集、全成就、角色扮演道具管理、卡牌收藏
- **推荐游戏**: 宝可梦、怪物猎人、各类RPG、卡牌游戏
- **口头禅**: "这个道具先囤着"

| 传奇老鹅 鹅 | 7 | ~7 |
| 648战士 氪 | 6 | ~7 |
| 老六鼠鼠 鼠 | 6 | ~7 |

> 编码时精确校验分值平衡，确保 8 个主要类型 7 次主分、4 个次要类型 6 次主分。副分浮动在 6-8 次范围内。

### 平局处理

得分最高的两个类型分差 ≤ 2 时，输出混合类型（如"受苦仙人 × 天亮战士"）。

## 5. 技术架构（不变）

- 前端: React 18 + Tailwind CSS + Vite，前端计分
- 后端: Node.js + Express + SQLite，持久化 + 统计
- Nginx 反向代理
- 前端 Canvas 预览 + 后端 node-canvas 生成分享图
- 动画: transform/opacity only
- 移动端优先

### API 端点

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/questions` | 返回 20 道题（不含分值） |
| POST | `/api/submit` | 提交答案，返回结果 |
| GET | `/api/result/:id` | 获取历史结果 |
| GET | `/api/stats` | 各类型人数统计 |
| GET | `/api/share/:id` | 后端生成分享图片 |

### 数据库

```sql
CREATE TABLE results (
  id TEXT PRIMARY KEY,
  answers TEXT NOT NULL,
  scores TEXT NOT NULL,
  result_type TEXT NOT NULL,  -- 'shouku' | 'shouku_tianliang' | ...
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
