========== 游戏人格测试 - 部署说明 ==========

目标服务器：Linux + 宝塔面板

----------------------------------------
一、上传文件
----------------------------------------
通过宝塔面板 → 文件管理器，将本目录所有文件
上传至 /www/wwwroot/game-personality/

----------------------------------------
二、安装依赖
----------------------------------------
打开宝塔 → 软件商店 → 安装 Node.js (≥18)

打开宝塔 → 终端，执行：

  cd /www/wwwroot/game-personality/server
  npm install

----------------------------------------
三、创建网站
----------------------------------------
宝塔 → 网站 → 添加站点：
  - 域名：你的域名（或 IP）
  - 根目录：/www/wwwroot/game-personality

----------------------------------------
四、配置反向代理
----------------------------------------
网站设置 → 反向代理 → 添加：

  代理路径：/api/
  目标 URL：http://127.0.0.1:3001

----------------------------------------
五、启动后端
----------------------------------------
宝塔 → 软件商店 → 安装 PM2 管理器 → 添加项目：

  启动文件：/www/wwwroot/game-personality/server/index.js
  项目目录：/www/wwwroot/game-personality/server/

或者通过终端：

  cd /www/wwwroot/game-personality/server
  node index.js

----------------------------------------
六、配置 SSL（推荐）
----------------------------------------
宝塔 → 网站 → SSL → 申请 Let's Encrypt

----------------------------------------
七、验证
----------------------------------------
浏览器访问 http://你的域名
完成测试后确认结果正常提交
访问 http://你的域名/api/stats 确认数据
